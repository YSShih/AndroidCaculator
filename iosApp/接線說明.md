# iOS 接線說明（需 macOS + Xcode；已在 macOS 實編＋iPhone 模擬器驗證通過）

## 前置
- macOS＋Xcode＋Kotlin Multiplatform Mobile 插件
- 本專案 `shared` 已含 `CalculatorStore`（`shared/src/commonMain/.../CalculatorStore.kt`）

## 步驟
1. `cd CalculatorKMM`
2. `./gradlew :shared:embedAndSignAppleFrameworkForXcode`
3. 用 Xcode 開 `iosApp/iosApp.xcodeproj`（scheme `iosApp` 已隨附在 `xcshareddata`，Signing 選 Team 即可跑實機/模擬器）
4. Target → Build Phases → 確認 `embedAndSignAppleFrameworkForXcode`；Framework Search Path 指向 `../shared/build/XCFrameworks/debug/`
5. `import shared`，`ContentView` 經 `CalcModel` 呼叫 `CalculatorStore.dispatch`，與 Android 共用同一 `reduce`
6. 跑 iPhone 模擬器，逐鍵對照 `shared/src/commonTest/.../CalculatorTest.kt` 的 13 個案例驗算

## 注意（以下已對 `shared.h` 驗證）
- Kotlin 嵌套類會扁平化：`CalculatorAction.Digit` 不存在，要用 `CalculatorActionDigit`（單例用 `CalculatorActionDot()` 等）；`CalculatorAction` 本體是 protocol
- Kotlin `Char` 對應 `unichar`（Swift 側 `UInt16`），數字鍵經 `CalcModel.digit(_:)` 由 `String` 轉碼；`CalculatorStore()` 無參數建構子是後加的（Swift 看不到 Kotlin 預設參數）
- `BinaryOp` 條目為小寫（`add/sub/mul/div/mod`），即 `BinaryOp.div` 寫法正確
- `%` 語義與 Android 一致：UI `%` 鍵＝單目百分比（÷100），表示式內 `%`＝二元求餘
